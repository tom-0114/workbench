# Workbench 待办界面重构

## 方向与范围

每天打开就能找到下一件要做的事。默认进入「今天」，任务是主角，日历用于安排时间。

参考用户指定的滴答清单品类：[官方新手指南](https://help.dida365.com/articles/6950689598586486784) 中的智能清单、标签分类与独立日历。借鉴信息组织关系，保留 Workbench 的名字、账号模型和已有数据结构。

采用 236px 左导航、弹性任务区域与点击任务后打开的 340px 详情区域。未选中任务时不预留空详情面板，把空间留给列表。浅灰导航配白色列表，蓝色用于操作和选中态；正文 14px，辅助信息 13px，沿用系统中文字体与项目 Lucide 图标。列表直接铺在画布上，取消装饰性卡片、渐变、指标面板。

设备：1100px 以上显示详情侧栏；768–1099px 用详情对话框；767px 以下隐藏侧导航，通过菜单打开，详情使用底部抽屉。320px–1920px 均有截图；720px 配 2 倍像素密度作为放大阅读后的等效布局检查，不把像素密度截图当成浏览器缩放。

## 页面与交互

- 今天：逾期、今日待办、今日已完成，底部显示实际完成进度。
- 最近 7 天：今天起的七天，待办按日期分组，重复任务按天展开。
- 全部任务：非重复任务及每个重复系列下一次未完成实例。
- 收集箱：无日期任务；快速添加默认为无日期。
- 标签：从已有任务标签生成分类，添加时继承当前标签。没有虚构的项目清单。
- 搜索：标题、备注和标签，支持 Ctrl+F；N 新建，T 今天；日历支持左右切换。
- 已完成、回收站、账号设置、备份与外观入口沿用现有功能。
- `?view=today|upcoming|all|inbox|completed|calendar|trash|search` 可直接打开对应视图，仍须走正常鉴权。

点击标题打开详情，勾选用于完成，更多菜单用于改期和删除。删除仍需二次确认。失败保留输入，成功后再清空；未保存的详情禁止被另一项任务替换。详情打开期间，在列表完成任务后，保存备注不会把完成状态覆盖回旧值。

动效：完成勾选短促反馈；详情向内滑入；首次进入主区与任务列表轻微出现；切换清单时任务区域过渡；进度条连续变化。减少动态效果时全部直接呈现。没有循环装饰动效。

## 精简

任务行中的多枚编辑、改期、删除按钮合并为一个更多入口。备注框删去「Shift+Enter 换行」提示，保留多行控件及原快捷键。详情不再重复「修改标题、日期与事项细节」说明；移动端只保留读屏说明。移除日历主屏上的侧栏分区堆叠，导航只显示类别和数量。未选中任务时删除空详情栏的图标、标题与指导句。
